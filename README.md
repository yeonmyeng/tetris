🧠 테트리스 알고리즘

테트리스 게임은 다음과 같은 알고리즘 흐름으로 동작합니다.

1️⃣ 새로운 블록 생성
2️⃣ 블록 이동 및 회전
3️⃣ 충돌 판정 수행
4️⃣ 블록 고정
5️⃣ 라인 완성 여부 검사
6️⃣ 라인 삭제 및 점수 증가
7️⃣ 게임 오버 여부 검사

이 과정이 반복되면서 게임이 진행됩니다.

⚙ 게임 루프 구조 (Game Loop)

게임은 게임 루프(Game Loop) 구조를 이용하여 동작합니다.

게임 루프는 다음 단계를 반복합니다.

1️⃣ 입력 처리
플레이어의 키보드 입력을 감지합니다.

2️⃣ 게임 상태 업데이트
블록을 이동시키고 충돌 여부를 확인합니다.

3️⃣ 화면 렌더링
Canvas API를 이용하여 현재 게임 상태를 화면에 그립니다.

이 과정이 빠르게 반복되면서 게임이 계속 진행됩니다.

🧱 블록 구조 (Tetromino)

테트리스 블록은 행렬(matrix) 형태로 정의됩니다.

예시 (T 블록)

0 1 0
1 1 1
0 0 0

행렬 회전을 이용하여 블록 회전 기능을 구현할 수 있습니다.

🔌 API / 주요 함수 설명 (Game API)

본 프로젝트는 서버 API를 사용하는 구조가 아니라 JavaScript 함수 기반으로 동작하는 게임 로직 API 구조로 구성되어 있습니다.
게임의 주요 기능은 tetris.js 파일에 정의된 함수들을 중심으로 동작합니다.

🎲 블록 생성 API
randomPiece()

랜덤한 테트리스 블록을 생성하는 함수입니다.

randomPiece()

설명

블록 종류 배열(TYPES)에서 랜덤한 블록을 선택합니다.

선택된 블록을 spawnPiece() 함수로 전달하여 새로운 블록을 생성합니다.

반환값

생성된 블록 객체

예시

const piece = randomPiece();
🧱 블록 생성 API
spawnPiece(type)

특정 블록 타입을 기반으로 새로운 블록을 생성합니다.

spawnPiece(type)

매개변수

파라미터	설명
type	블록 종류 (I, O, T, S, Z, J, L)

반환값

{
 type,
 shape,
 x,
 y
}

설명

블록 모양(shape)

초기 위치(x, y)

를 포함한 블록 객체를 생성합니다.
